Phytium SPI-V2 controller

Required properties:
- compatible: should be "phytium,spi-2.0"
- #address-cells: see spi-bus.txt
- #size-cells: see spi-bus.txt
- reg: address and length of the regfile and sharememory
- interrupts: should contain one interrupt
- clocks: spi clock phandle
- num-cs: see spi-bus.txt

Optional properties:
- cs-gpios: see spi-bus.txt

Example:


spi0: spi@27014000 {
	compatible = "phytium,spi-2.0";
	interrupts = <GIC_SPI 18 IRQ_TYPE_LEVEL_HIGH>;
	reg = <0x0 0x27014000 0x0 0x1000 0x0 0x27007000 0x0 0x1000>;
	clocks = <&sysclk_48mhz>;
	num-cs = <4>;
};
